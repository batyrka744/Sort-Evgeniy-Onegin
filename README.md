# Sort-Evgeniy-Onegin
Программа на Си, которая сортирует текст на английском

!Возможности программы:
1) Читать английский текст с входного файла
2) Выводить отсортированный текст в файл
3) Сортировать строки текста по алфавиту
4) Сортировать по алфавиту с конца строки(по рифме)
5) Вывести оригинал текста
6) Не выводить строки без букв
7) Выводить ссылки на каждую сортировку в консоль

При сортировке сравниваются только английские буквы. Сортировка по алфавиту происходит "пузырьком", из-за чего на неё уходит много времени.
Сортировка по рифме выполняется с помощью встроенной в стандартную библиотеку функцию qsort.
